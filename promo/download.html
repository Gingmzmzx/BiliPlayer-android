把 B 站收藏夹
变成随身播放器

BiliPlayer 用一个无头浏览器打开 B 站页面，把视频里的声音播出来，
同时接管系统媒体控制。不用守着电脑，也能把收藏夹当歌单听。

灵动岛 / 胶囊通知里直接显示正在播放的歌——封面、进度、上下曲都能点，不只是锁屏。

功能详解

每一个细节

收藏夹抓取

填入 B 站 UID 与收藏夹名称，应用会在后台用一个无头浏览器打开收藏夹页面，自动点击进入目标收藏夹并读取每条视频。

  • 真实触摸事件：用真实手势点击侧栏，绕过 isTrusted 检测
  • 自动翻页：一路翻到「下一页」不可用为止
  • 实时进度：显示「第 X 页 / 共 Y 页，已抓取 N 个 / 共 M 个」
  • 抓取失败时可手动介入，点一下对应收藏夹即可继续
零 API 调用 纯 DOM 解析

抓取进度

抓取过程中顶部实时显示进度：翻到第几页、总共几页，已经抓到多少个、一共多少个。抓取和播放共用同一个浏览器，不用时它只是安静待在屏幕外。

  • 翻页进度：「第 X 页 / 共 Y 页」实时更新
  • 曲目计数：「已抓取 N 个 / 共 M 个」
  • 总数还没拿到时显示不确定进度条，不会假装有百分比
  • 点失败可手动介入：直接点画面里的收藏夹项就能继续

登录 B 站

应用内置一个 PC 端登录页，登录后即可访问私密收藏夹。登录状态仅保存在本机 WebView 中。

  • 桌面版 UA，登录体验与电脑一致
  • Cookie 只存本地，应用不做任何上传
  • 抓取收藏夹时自动携带登录态

播放器

抓取完成后自动进入播放器开始播放。界面包含完整的播放控制，并且可以上下滚动，小屏也不会挤掉控件。

  • 进度条：实时显示，可拖动跳转
  • 上一首 / 播放暂停 / 下一首
  • 音量滑块，默认音量会被记住
  • 隐藏画面时显示高清封面

  • 自动网页全屏，无需手动点击
  • 自动隐藏控制条，画面更干净
  • 一键切换显示 / 隐藏，隐藏时回到封面模式
  • 播放中画面不可误触，避免跳转

重点

灵动岛 & 系统媒体控制

应用注册了完整的系统媒体会话（MediaSession + 前台服务）， 所以系统会把正在播放的歌显示在灵动岛 / 胶囊通知上—— 封面、进度条、上一首下一首都在那颗胶囊里，不只是锁屏才有。

  • 灵动岛 / 胶囊通知：亮屏、切到别的应用时也能看到当前歌曲，直接点按控制
  • 锁屏：显示封面与进度，可拖动跳转
  • 通知栏：上一首 / 播放暂停 / 下一首常驻按钮
  • 蓝牙耳机：播放暂停与上下曲按键全部生效
  • 进度、时长、封面与播放状态实时同步，拖动不跳歌

➡️

顺序播放

随机播放

常见问题

为什么抓取收藏夹会失败？
首次启动时浏览器内核需要初始化，可能稍慢。若自动点击未命中，页面会提示你手动点一下上方的收藏夹，点完会自动继续。另外，收藏夹需要是公开的，私密收藏夹请先登录 B 站账号。
会读取或上传我的 B 站账号信息吗？
不会。登录 Cookie 只保存在本机浏览器的存储中，应用不收集、不上传任何账号数据到服务器。你可以随时清除应用数据来退出登录。
为什么抓到的视频数量比页面上显示的总数少？
这是 B 站分页本身的显示问题，页面统计数与实际可读取的条目数有时不一致。应用以实际抓取到的结果为准。
为什么有些视频会自动跳过？
视频可能已被删除、设为私密或仅限特定地区访问。应用检测到「视频不见了」会自动切到下一首，并尽量从中断位置恢复播放。
后台播放会被系统杀掉吗？
应用使用前台服务常驻播放。如果仍被中断，请在系统设置中允许本应用后台运行，或将应用加入电池优化白名单。
显示画面后为什么点不动？
播放时为避免误触跳转，画面区域默认屏蔽触摸。使用应用内的控制区和系统通知即可操作播放。
灵动岛 / 胶囊通知上没有显示歌曲？
灵动岛由系统提供，能显示什么由系统决定，不同品牌、不同系统版本的形态与支持程度都不一样（有的叫灵动岛，有的叫胶囊、焦点通知）。 只要应用在播放，系统媒体会话就是激活状态，支持该能力的系统会自动把歌曲显示上去； 若系统不支持，则退化为通知栏与锁屏控制，功能不受影响。同时请确认已授予通知权限、且未在系统设置里关闭本应用的通知。
