WHAT IS IT

把 B 站收藏夹，变成随身播放器

BiliPlayer 不是又一款客户端，而是一次「用浏览器当播放器」的尝试。
它用一个离屏 WebView 打开 B 站页面，把视频里的音频播出来，
同时接管系统媒体控制，让你像用本地播放器一样听收藏夹。

  • 不需要 B 站账号也能听公开收藏夹
  • 不调用任何 B 站 API，完全模拟真实浏览器
  • 退到后台、锁屏、切应用，音乐都不中断
STEP 1

输入 UID 与收藏夹

填入 B 站 UID 和收藏夹名称，一键开始。所有配置都会自动保存，下次打开无需重填。

  • UID：B 站空间地址中的数字
  • 收藏夹名：需为公开收藏夹
  • 自动全屏：可选，勾选后播放时自动进入网页全屏
  • 登录入口：可直接登录 B 站账号

LOGIN

登录 B 站，解锁私密收藏夹

应用内置一个 PC 端登录页，使用桌面版 UA，登录体验与电脑一致。登录后即可访问私密收藏夹。

  • Cookie 只存在本地 WebView，应用不做任何上传
  • 抓取收藏夹时自动携带登录态
  • 随时可退出登录，不留痕迹
SCRAPING

无头浏览器抓取收藏夹

离屏 WebView 打开收藏夹页面，模拟真实鼠标与触摸完成点击，抓取每条视频的 BV 号、标题与封面。

  • 真实触摸事件：绕过 isTrusted 检测
  • 自动点击侧栏收藏夹，失败时提示手动介入
  • 纯 DOM 解析，零 API 调用

PAGINATION

自动翻页，抓完为止

收藏夹有几十上百条视频时，会自动翻页继续抓取，直到「下一页」按钮变成不可用。

  • 解析分页信息：「共 X 页 / Y 个」
  • 实时进度条：第 X 页 / 共 Y 页
  • 元素未就绪时显示无限加载动画，不显示假进度
  • 受 B 站自身限制，实际抓取数可能少于页面显示的总数

PLAYER

播放器主界面

抓取完成后自动进入播放器，开始播放第一首（随机模式下随机挑选起点）。

  • 进度条：实时显示，可拖动跳转
  • 控制区：上一首 / 播放暂停 / 下一首
  • 音量滑块与播放模式一键切换
  • 隐藏画面时显示高清封面
PLAY MODE

三种播放模式

➡️

顺序播放

按收藏夹顺序依次播放，播完回到第一首。

🔀

随机播放

无重复洗牌：整轮内不重复，播完一轮自动重新洗牌。

🔂

单曲循环

反复播放当前这首，直到你手动切换。

随机模式还会在启动时随机挑选起始曲目，不会每次都从第一首开始。

MV MODE

边听边看 MV

点击「显示画面」，WebView 就会呈现在界面上方。视频加载完成后自动进入网页全屏，并隐藏播放器控制条，沉浸式观看。

  • 自动网页全屏，无需手动点击
  • 自动隐藏控制条，画面更干净
  • 一键切换显示 / 隐藏，隐藏时回到封面模式
  • 播放时画面不可误触，避免跳转

PREFERENCE

单曲偏好：分P、开始、结束

每一首歌都可以单独配置，按 BV 号独立保存，下次播放自动生效。

  • 分 P：选择播放第几个分 P
  • 开始秒：跳过片头，直接进入正题
  • 结束秒：到点自动切下一首（自动截断）
  • 设置仅对当前曲目生效，互不影响

BACKGROUND

退到后台、锁屏，音乐不停

应用使用前台服务常驻，并配合部分唤醒锁与一个始终保持渲染的 WebView，让音频在各种场景下持续播放。

  • 前台服务保活，切应用不中断
  • 锁屏、息屏继续播放
  • 灵动岛 / 胶囊通知实时显示当前歌曲，直接点按控制
  • 状态丢失自动重载，并续播到上次位置
  • 视频失效自动切换下一首

UNDER THE HOOD

技术实现

WebView
离屏无头浏览器：不占用界面，但始终保持渲染，让 B 站的懒加载、IntersectionObserver 正常工作，否则页面内容根本抓不到。
Touch
真实触摸事件：用 dispatchTouchEvent 注入真实手指点击。JS 的 element.click() 是 isTrusted=false 的非可信事件，会被 B 站忽略。
Scraping
纯 DOM 抓取：解析收藏夹页面结构，自动翻页，不调用任何 B 站 API，也不依赖任何第三方接口。
MediaSession
系统媒体会话：接管锁屏、蓝牙与通知栏，播放进度与封面毫秒级同步，并支持从系统侧拖动进度。
